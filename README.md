# Kevin Soto — Engineering Portfolio

A responsive personal portfolio for **Kevin Soto**, an Electrical and Computer Engineer focused on:

- Electrical testing and troubleshooting
- Embedded systems
- FPGA and digital design
- Test automation
- Robotics and computer vision

The website uses only **HTML, CSS, and JavaScript**, so it can be hosted free with GitHub Pages.

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in a browser.

For a more realistic local preview, use the VS Code **Live Server** extension.

## Publish with the repository you already created

Your current repository is:

```text
github-portfolio
```

Upload all files from this folder into that repository, then:

1. Open the repository on GitHub.
2. Select **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Save.

The project-site address should follow this format:

```text
https://kevinsj9898-star.github.io/github-portfolio/
```

## Important edits before sending the portfolio to recruiters

### 1. Add your résumé

Create this file:

```text
assets/Kevin_Soto_Resume.pdf
```

Then add a résumé button to the hero or contact section.

### 2. Add LinkedIn

Add your exact LinkedIn URL to the hero and contact section.

### 3. Prepare project repositories

Each featured project should eventually have its own public repository with:

- A strong README
- Photographs or diagrams
- Problem statement
- Design approach
- Hardware and software used
- Setup instructions
- Results
- Lessons learned

### 4. Protect confidential information

Do not upload proprietary Schneider Electric drawings, customer information,
test procedures, internal screenshots, serial numbers, or factory photographs
that were not approved for public use.

### 5. Replace general descriptions with measured results

When available, add numbers such as:

- Number of test cases completed
- Timing improvement
- Communication rate
- Tracking accuracy
- FPGA resource utilization
- Maximum verified operating frequency

Measured results make engineering projects more credible.
